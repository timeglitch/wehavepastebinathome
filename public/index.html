GitHub

Copy and paste with an easy-to-type URL. End-to-end encryption if you need it.

How does encryption work?

With Encrypt on, your computer encrypts the paste before sending it, so the server won't see your data. If you don't set a password, your computer will generate a random one and embed it in the link for you.

Your message is encrypted with AES-256-GCM. The server can still see the title, language and expiry.

What is this?

A small pastebin: paste text, get a link. Give it a title for an easy-to-type URL like /my-notes, or leave it blank for a random one. Pastes can expire after an hour, a day, a week or a month, or stay up.

This is a personal project I made because I found other solutions annoying. I've never lost a paste, but I cannot guarantee your pastes will stay up forever.

Terminal usage is supported:

# upload: prints the link
cat notes.txt | curl --data-binary @- 'https://paste.frankzhang.org/api/paste?title=notes'
# read it back
curl https://paste.frankzhang.org/raw/notes
